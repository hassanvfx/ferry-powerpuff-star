# Decisions

- La pasada inversa fija la primera aparición permitida y luego propaga esa restricción hacia adelante. La referencia de página previa sólo conserva apariencia; nunca crea derechos para introducir objetos futuros.
- Los bloqueos usan ausencias explícitas, no sólo una descripción positiva. Esto reduce la tendencia del modelo a decorar temprano el laboratorio con props románticos o mágicos.
- La inspección de arte será una puerta humana adicional: el verificador prueba que el prompt contiene la regla, no que el modelo de imagen la obedeció.
