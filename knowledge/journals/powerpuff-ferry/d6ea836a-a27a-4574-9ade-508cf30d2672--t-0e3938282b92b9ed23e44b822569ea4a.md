# Goal

Crear una corrida V9 aislada guía→final que tome las referencias visuales de
cada bloque fuente `REFERENCIAS DECLARADAS PARA ESTA PÁGINA` y deje una
evidencia exacta de los adjuntos que llegan al payload.

# Task Contract

- Intended outcome: un gestor V9 y una configuración nueva de 90 páginas,
  2K, 2:3, que mantengan la dependencia guía→final y sustituyan la selección
  codificada de estilo/personajes por el inventario declarado en cada prompt.
- Observable success criteria: para una página el dry-run enumera todas sus
  fichas declaradas, incluidas las candidatas autorizadas por defecto. Las
  snapshots de guía y final comienzan con
  `REFERENCIAS VISUALES ADJUNTAS` y la lista coincide, en orden, con cada
  `--image` que se enviaría. El final añade además exclusivamente su PNG guía.
- Constraints and non-goals: no modificar prompts fuente, guías, plan, V3–V8
  ni enviar a Kie; no reutilizar directorios de corridas previas ni adjuntar
  páginas narrativas anteriores. Las candidatas autorizadas se adjuntan por
  defecto en V9.
- Open questions and assumptions: los paths declarados son relativos a
  `libro/produccion`; guía y final reciben las mismas fichas de continuidad,
  y el final suma el PNG guía como dependencia generada.

# Execution Boundaries

# Work Log

- Se inspeccionó el formato real de las 90 fuentes: cada bloque declara
  `status`, `type`, id, ruta relativa y uso. La página 16 declara estilo,
  Hassan, Ferry, Zeus v3 y el jardín protector; el auditor existente confirma

  aislada `corrida-90-2k-2-3-v9-referencias-guia.json`. V9 importa el
  orquestador guía→final sólo como base de estado y sustituye, en memoria, la
  materialización y submit por lectura directa de las declaraciones; V3–V8 no
  fueron modificados.
- Para ambas fases, la snapshot empieza con `REFERENCIAS VISUALES ADJUNTAS`.
  La guía adjunta las fichas seleccionadas y el final adjunta esas mismas

- Las candidatas se adjuntan por defecto, como autorizó el autor. La opción
  heredada `--include-candidate-continuity-assets` sigue aceptándose, pero no
  cambia ese comportamiento.

# Decisions

- La declaración del prompt es la autoridad de selección en V9; el índice de
  continuidad queda como catálogo/auditoría existente, no como sustituto de
  una declaración de página.
- V9 conserva `gpt-image-2`, 2K, 2:3, cinco jobs activos, pausa de tres
  segundos, tres reintentos, parada por falta de créditos y cero adjuntos de
  página anterior.
- No se ejecutó `--live`, no se creó cron ni heartbeat y no se tocaron las
  salidas o recibos de otras corridas.
- El autor promovió operativamente las fichas candidatas a adjuntos por
  defecto para V9; se eliminó la necesidad del flag de inclusión.
- La corrida V9 finalizó con 82 finales correctos. Siete guías agotaron sus
  reintentos por el límite de longitud de texto de Kie; el final 90 recibió un
  error interno 500. Se añadió `--retry-failed`, que sólo borra el registro de
  fallo, intentos y backoff de las fases seleccionadas y nunca borra PNGs o
  recibos archivados.
- La documentación local de `gpt-image-2` declara máximo de 20,000
  caracteres. Las snapshots confirman el borde: 19,888 caracteres pasó
  (página 69); 20,002 caracteres falló (página 28). Las demás guías fallidas
  miden 20,006 o entre 22,923 y 23,048 caracteres.
- Se añadió el paso reusable `preparar_prompts_ejecucion_v9.py`. Copia las
  180 versiones materializadas a `preparados/originales`, prepara sus
  versiones de ejecución en `preparados/guias` y `preparados/finales`, y
  publica `preparados/revision.json` con rutas, referencias y longitudes
  antes/después. Sólo compacta una guía si excede 20,000 caracteres.
- Se generaron las 180 versiones V9: siete guías se compactaron de 20,002–
  23,048 a 11,783–13,014 caracteres. El gestor ahora busca primero su copia
  preparada; sólo usa la fuente si todavía no existe una versión preparada.
- Las 90 guías fuente cambiaron posteriormente de forma coherente. El lock V9
  detectó el drift (`c4ca…` frente a `a239…`) y bloqueó el envío. Se aceptó el
  nuevo lote, se actualizó el lock a `a239cef78c5d995fe2f0024ca0e9c0d6b78b86cb1f86209bd5189380117ac9b5`
  y se regeneraron las 180 copias preparadas con `--replace`; ninguna supera
  el límite y ya no fue necesaria una compactación adicional.
