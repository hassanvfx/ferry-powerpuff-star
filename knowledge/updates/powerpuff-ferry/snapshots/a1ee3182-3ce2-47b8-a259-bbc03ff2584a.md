# Goal

Permitir una revisión privada y local del cómic sin exponer controles ni notas en la lectura normal.

# Task Contract

- Intended outcome: activar con `?review=true` un engrane junto al avatar que abre un modal para crear, editar, borrar y exportar anotaciones por imagen.
- Observable success criteria: cada nota conserva `page` y `note` por edición en `localStorage`; la lista permite editar y borrar una o todas; Exportar copia un JSON con `edition` y `notes` al portapapeles.
- Constraints and non-goals: player HTML/CSS/JS plano, sin backend ni telemetría; la interfaz y las notas no existen para URLs sin el parámetro exacto `review=true`.
- Open questions and assumptions: portada y contraportada se codifican como `cover` y `back-cover`; las páginas interiores usan su número entero.

# Execution Boundaries

- Authorized scope and exclusions: `app.js`, `styles.css`, el publicador, guía de operación, sus copias generadas en `docs/` y este journal; no se cambia arte ni Pages. El autor autorizó explícitamente una publicación V9 parcial.
- Affected interfaces, owners, and relevant side effects: `localStorage` añade una llave por edición para notas de revisión y la Clipboard API recibe sólo la exportación iniciada por la persona.
- Escalate before changing requirements, external behavior, authority, ownership, dependencies, or acceptance criteria: sincronización remota, cuentas, compartir enlaces de notas o habilitar el modo fuera de `?review=true`.
- Delegation integrator and remaining integration checks, when applicable: sin delegación; Codex compone la UX, persistencia y artifact publicado.

# Handoff Topology

- Selection: un único handoff, porque la interfaz, la persistencia y el payload de exportación forman una misma frontera de revisión local.
- Parent integrator and final end-to-end acceptance, when applicable: Codex prueba en navegador desktop/móvil y valida las copias fuente/publicada.
- Milestones: no aplica; el fallo de Clipboard API deja las notas intactas y muestra un estado de permisos.

# Decisions

- El engrane acompaña al avatar en interiores y se mantiene visible en cubiertas cuando `?review=true`, para que portada y contraportada también puedan recibir una nota.
- Al fallar el permiso de Clipboard API no se pierden las notas: el modal muestra el error y conserva el contenido local.
- `--allow-gaps` sólo se acepta por decisión explícita: conserva números originales, exige pares final/guía y total par, mientras `--latest` permanece estricto.
- V9 no incluye la página 90 porque sólo existe su guía y todo final publicado requiere guía correspondiente; sus guías extra se ignoran de forma segura.
