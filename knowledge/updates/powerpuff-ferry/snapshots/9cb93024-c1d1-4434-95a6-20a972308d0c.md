# Goal

Entregar un visor estático del cómic y un flujo manual de publicación desde `docs/` hacia GitHub Pages.

# Task Contract

- Intended outcome: un publicador local selecciona una corrida explícita o la final más reciente, genera `docs/` de forma atómica y el workflow despliega sólo ese contenido tras un push humano a `main`.
- Observable success criteria: el publicador valida una secuencia interior continua y par, exige ambas cubiertas, genera manifest y WebP; el player muestra portada, dobles páginas en desktop y feed vertical en móvil; el workflow sube `docs/` como artifact de Pages.
- Constraints and non-goals: frontend sin framework ni backend; no generar arte ni enviar trabajos de imagen; no publicar ni hacer push durante esta tarea; no tocar los cambios editoriales existentes del autor.
- Open questions and assumptions: los dos assets aportados se guardan como referencias versionadas; el primer despliegue remoto sigue pendiente de un remoto GitHub y un push humano.
