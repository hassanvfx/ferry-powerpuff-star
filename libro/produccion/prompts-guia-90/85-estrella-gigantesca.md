# Prompt de storyboard anotado 85 — Estrella gigantesca

Genera una sola LÁMINA DE PREVISUALIZACIÓN: storyboard anotado de dirección de arte para la página 85, formato vertical 2:3. Esto NO es una página final de cómic ni una ilustración terminada. Dibuja exactamente 2 celdas con la retícula indicada, en papel marfil de cuaderno de producción. Estética obligatoria: OUTLINE SKETCH DRAFT, líneas de construcción a lápiz grafito y azul, contornos negros deliberadamente incompletos, figuras en maniquí semi-chibi adulto con línea de acción visible, sombreados de trama muy ligeros, flechas de movimiento y mirada, horizonte y líneas de fuga, y bloques simples de valores. Usa acentos codificados: azul frío para arquitectura/luz nocturna, coral para Ferry o foco emocional, amarillo para fuente de luz, rojo para props o continuidad crítica.

Cada celda necesita una franja estrecha de anotaciones en su canaleta exterior: código C#, mini-icono de cámara, dirección de cámara, flecha de mirada, flecha de luz, línea de acción, horizonte y círculo rojo al prop crítico. Añade siete micro-notas de continuidad, preferentemente como iconos y códigos: ID (personaje), VEST (ropa/accesorios), ESP/T (lugar/hora), CAM (encuadre), CUERPO (pose/apoyo), PROP (estado de utilería) y RELEVO (qué estado sale a la próxima celda). Dentro de la viñeta debe verse el esqueleto gestual antes del volumen, tres capas de profundidad (frente/medio/fondo) y flechas que expliquen dónde se mueve o mira cada figura. Las anotaciones son gráficas, breves y funcionales; no son decoración.

Placa de especie para ESTA página: DOS CARACOLES TERRESTRES | UNA ARAÑA TEJEDORA — 8 PATAS. Dibuja únicamente esas criaturas en las celdas que su bloqueo individual las autoriza; no uses iconos genéricos ni introduzcas las otras criaturas de la historia.

En su lugar, dentro de cada celda dibuja: encuadre de cámara, línea de horizonte/profundidad, silueta y esqueleto gestual, flecha de mirada, flecha de movimiento, fuente de luz, icono de prop y contorno vacío donde irá el lettering. El texto de abajo es información para orientar el sketch; sólo pueden aparecer marcas técnicas brevísimas como C1, H1, F1, N1 o SFX-1, nunca frases completas.

- Retícula: dos celdas verticales: izquierda 42%, derecha 58%.

- Sistema gráfico visible en CADA celda: flecha de mirada + flecha de movimiento + flecha de luz + icono/círculo de prop + silueta de lettering vacía.
