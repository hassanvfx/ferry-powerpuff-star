# Prompt de storyboard anotado 02 — Última revisión

Genera una sola LÁMINA DE PREVISUALIZACIÓN: storyboard anotado de dirección de arte para la página 02, formato vertical 2:3. Esto NO es una página final de cómic ni una ilustración terminada. Dibuja exactamente 3 celdas con la retícula indicada, en papel marfil de cuaderno de producción. Estética obligatoria: OUTLINE SKETCH DRAFT, líneas de construcción a lápiz grafito y azul, contornos negros deliberadamente incompletos, figuras en maniquí semi-chibi adulto con línea de acción visible, sombreados de trama muy ligeros, flechas de movimiento y mirada, horizonte y líneas de fuga, y bloques simples de valores. Usa acentos codificados: azul frío para arquitectura/luz nocturna, coral para Ferry o foco emocional, amarillo para fuente de luz, rojo para props o continuidad crítica.

Cada celda necesita una franja estrecha de anotaciones en su canaleta exterior: código C#, mini-icono de cámara, dirección de cámara, flecha de mirada, flecha de luz, línea de acción, horizonte y círculo rojo al prop crítico. Añade siete micro-notas de continuidad, preferentemente como iconos y códigos: ID (personaje), VEST (ropa/accesorios), ESP/T (lugar/hora), CAM (encuadre), CUERPO (pose/apoyo), PROP (estado de utilería) y RELEVO (qué estado sale a la próxima celda). Si aparece un animal, el campo ID debe llevar además una placa roja de ESPECIE/RAZA con su nombre literal y un mini-estudio de silueta: Zeus debe rotularse ROTTWEILER negro y fuego, Yohi TORTUGA SULCATA, los caracoles DOS CARACOLES TERRESTRES y la araña ARAÑA TEJEDORA — 8 PATAS. No uses un icono genérico de perro, tortuga, caracol o insecto. Dentro de la viñeta debe verse el esqueleto gestual antes del volumen, tres capas de profundidad (frente/medio/fondo) y flechas que expliquen dónde se mueve o mira cada figura. Las anotaciones son gráficas, breves y funcionales; no son decoración.

NO dibujes arte final, pintura digital pulida, cel shading terminado, superficies brillantes, 3D, fotorrealismo, fondos resueltos, globos de diálogo terminados, SFX terminados, cartelas acabadas, logos, letreros inventados ni texto literal. En su lugar, dentro de cada celda dibuja: encuadre de cámara, línea de horizonte/profundidad, silueta y esqueleto gestual, flecha de mirada, flecha de movimiento, fuente de luz, icono de prop y contorno vacío donde irá el lettering. El texto de abajo es información para orientar el sketch; sólo pueden aparecer marcas técnicas brevísimas como C1, H1, F1, N1 o SFX-1, nunca frases completas.

## Formato de página

- Retícula: una viñeta superior de 48%; dos viñetas inferiores iguales.
- Número de celdas: 3. Lectura: arriba-izquierda a abajo-derecha.
- Seguridad: rostros, manos, globos y objetos focales a mínimo 10% de cada borde; anatomía adulta semi-chibi, dos brazos, dos piernas y manos de cinco dedos.
- Sistema gráfico visible en CADA celda: flecha de mirada + flecha de movimiento + flecha de luz + icono/círculo de prop + silueta de lettering vacía.
