# Prompt de storyboard anotado 03 — El libro rosa

Genera una sola imagen-guía de storyboard anotado para la página 03, formato vertical 2:3. No es la ilustración final: es una composición técnica visual que el orquestador usará como referencia antes de generar la página final. Dibuja exactamente 2 celdas con canaletas limpias y la retícula indicada. Cada celda debe conservar el encuadre, personajes, vestuario, lugar, luz, pose, mirada, objetos, texto y SFX especificados abajo. Usa siluetas adultas semi-chibi coherentes con las hojas v2, bloques de color simples y anatomía clara; no uses fotorrealismo, render 3D, textura pictórica, decoración libre, personajes extra ni letras fuera de las declaradas.

## Formato de página

- Retícula: dos celdas verticales: izquierda 42%, derecha 58%.
- Número de celdas: 2. Lectura: arriba-izquierda a abajo-derecha.
- Seguridad: rostros, manos, globos y objetos focales a mínimo 10% de cada borde; anatomía adulta semi-chibi, dos brazos, dos piernas y manos de cinco dedos.
