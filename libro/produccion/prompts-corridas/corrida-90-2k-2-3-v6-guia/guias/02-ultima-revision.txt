Genera una sola imagen-guía de storyboard anotado para la página 02, formato vertical 2:3. No es la ilustración final: es una composición técnica visual que el orquestador usará como referencia antes de generar la página final. Dibuja exactamente 3 celdas con canaletas limpias y la retícula indicada. Cada celda debe conservar el encuadre, personajes, vestuario, lugar, luz, pose, mirada, objetos, texto y SFX especificados abajo. Usa siluetas adultas semi-chibi coherentes con las hojas v2, bloques de color simples y anatomía clara; no uses fotorrealismo, render 3D, textura pictórica, decoración libre, personajes extra ni letras fuera de las declaradas.

- Retícula: una viñeta superior de 48%; dos viñetas inferiores iguales.
