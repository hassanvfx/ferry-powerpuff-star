# Guion técnico — 90 páginas con diálogo

Este dossier es la especificación de producción. Cada página define retícula, orden de lectura, cámara, acción y el único texto permitido. Todo texto literal va entre comillas dobles. Las etiquetas técnicas no se imprimen: sólo se imprime el valor de `Texto impreso exacto`. `SILENCIO` significa que no puede aparecer ningún globo ni letra en esa celda. Las cartelas pertenecen al narrador omnipresente; las nubes son pensamientos interiores de Hassan; Ferry habla con una voz adulta Gen Z cálida y ligera. En las páginas 66–77 Hassan enumera en pantalla los ingredientes 1–29 y cada aparición arquetípica de Ferry es un diseño original, no una copia de una figura evocada.
